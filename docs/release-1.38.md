# Реліз 1.38 — виправлення оцінки конкурсу

До переходу далі ведучий може виправити команду й бали поточного результату
або вибрати «Без балів». Дія доступна в особистому пульті та через
«Керування грою» на спільному екрані. Вікно використовує наявні кнопки
React Bits, кольори команд та TV-масштаб типографіки. Нових залежностей немає.

Сервер віднімає попереднє нарахування й додає нове. Порядок команд,
відкрита відповідь, підказки та голоси не переграються. Межа балів відповідає
правилам конкурсу й використаним підказкам: це ручне рішення ведучого,
а не повторний розрахунок швидкості відповіді. Після переходу до наступного
конкурсу або фіналу виправлення закрите.

Повторний чи запізнілий запит не додає бали вдруге: перевіряються номер
конкурсу й версія оцінки. Гравці та глядачі не можуть змінювати її.
Збережено перше нарахування й кількість виправлень, включно після
відновлення кімнати. Це не журнал кожної проміжної оцінки. Поточний
результат і фінальна історія мають позначку «Бали виправив ведучий».

## Перевірка

130 фронтенд-тестів, typecheck і production build пройшли. Go tests і vet
пройшли. Нові серверні тести охоплюють усі п'ять конкурсів, межі балів,
права ведучого, дробові/від'ємні значення, застарілі запити, повторне
нарахування, фінальну історію та відновлення зі snapshot.

Локальний WebSocket-сценарій перевірив ведучого, гравця й глядача:
4:0 → 0:3 → 0:0 → 4:0, незмінну відповідь та фінальну історію.
У браузері пройдено перенесення оцінки, відмову від нарахування,
скасування без збереження, перезавантаження пульта й перехід до фіналу.
Форма не має горизонтального переповнення на 320 px, включно з назвами
команд із 32 широких кириличних символів. На Full HD шрифт дій — 27 px,
на 4K — 54 px; відповідні заголовки — 59,4 та 112 px.

Повне аудіо Deezer залишається [незавершеним](music-playback.md).
