# Реліз 1.13 — послівні мітки Deezer

Музичний адаптер запитує не лише `synchronizedLines`, а й
`synchronizedWordByWordLines { start end words { start end word } }`.
Це справжні мітки провайдера. Час не ділиться за кількістю літер чи слів.
Проміжки між словами, короткі слова та точні початки й закінчення збережені.

На перевірених записах BIRDS OF A FEATHER Billie Eilish (2801558052) отримано
39 послівних рядків і 298 міток; Levitating Dua Lipa (1124841682) — 88 і 526.
Поточний API та ці відповіді перевірено 3 листопада 2026 року. У перевірених
«Порічка», «Плакала (2022, Bonus track)» та «Обійми» джерело надало лише рядки.
Наявність такого поля в API не означає однакове покриття всього каталогу.

Студія та телефонний пульт явно показують тип підсвічування і кількість
рядків із валідними мітками слів. За повного послівного тексту в редакторі
вже є готові мітки Deezer: їх можна прослухати, скоригувати або експортувати
в Enhanced LRC. Підготовка пісні зберігає їх разом з аудіо та рядком для гри.
Для записів без послівних даних залишається підсвічування рядками, імпорт
LRC і ручний редактор слів. Неповне покриття показується як неповне.

Повне послівне джерело може мати точніші межі рядків. Його шкала приймається
лише коли повністю відповідає початковому тексту в правильному порядку.
Часткові мітки додаються тільки до відповідного рядка в його часових межах;
відсутні слова не домислюються. Некоректне необов’язкове поле не видаляє
придатні рядкові мітки. Старіша схема API має один повтор із рядковим запитом.

Коли при звичайному відкритті треку змінилися межі рядків або текст,
попередню прив’язку потрібно перевірити знову. Додавання лише слів усередині
тих самих рядків її не скидає. Збережена підготовка відкриває власний знімок
тексту, тому оновлення провайдера його не переписує. Глядацька проєкція
вибирає той самий останній початий рядок, що й локальна сцена; перекриття
не повертає старий рядок у тиші й не показує майбутню відповідь.

Ключ Deezer залишається лише на сервері. Для послівного підсвічування немає
нових завантажень моделей, розпізнавання на TV або передачі власного аудіо
до зовнішнього сервісу. Дослід із локальним Whisper не ввійшов у продукт:
його якість на перевіреному музичному фрагменті була недостатньою.

Послівні мітки належать шкалі повного запису. Для прев’ю або іншого аудіо
потрібно перевірити часову прив’язку; сам тип підсвічування її не підтверджує.
Повне захищене відтворення Deezer залишається неінтегрованим. Підключення
WTAdmin дає бібліотеку й тексти, але не готовий програвач у цій платформі.
