# Реліз 1.37 — актуальні нові екрани й вхід за кодом

Нові посилання глядача, TV зі звуком, приватного мережевого пульта та
гостьові запрошення тепер відкривають наявний /api/app-shell. Цей маршрут
отримує оболонку з мережі та обходить кеш навігації старого service worker.
Після завантаження адреса повертається до звичайної, як у вході відновлення.
Зміна стосується згенерованих оновленим застосунком URL, включно з QR і копіями.
Старі вкладки та збережені раніше URL не перезавантажуються примусово.

Ключі TV і приватного пульта залишаються у фрагменті URL; параметри ролі,
кімнати й звуку збережені. Спільний appEntryURL не змінює чужі origin,
класичний застосунок, API чи невідомі екрани.

Локальна BroadcastChannel-сцена й вхід у музичну підготовку з головної
використовують кешований корінь, якщо браузер повідомив offline. Події
online/offline оновлюють URL локальної сцени. Це ознака стану браузера,
а не перевірка всіх мережевих відмов: [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/onLine).
Захист активної гри від оновлення service worker не змінений.

Вхід із головної за шестисимвольним кодом студії тепер передає room,
який очікує RoomAudience. Раніше передавався code, тому кімната губилася.
П’ятисимвольний код конкурсів продовжує передаватися як code.

## Перевірка

130 фронтенд-тестів, typecheck, production build, Go tests і vet пройшли.
17 нових випадків перевіряють маршрути, обидва формати коду, фрагменти
приватних ключів, ролі TV, офлайн-корінь та незмінність сторонніх адрес.

У браузері з головної відкрито власну локальну кімнату студії DV7MZK за
шестисимвольним кодом: сцена отримала правильні команди. Приватний пульт
успішно авторизувався через новий маршрут, ключ прибрано з адреси. П’ятисимвольний
код 6U788 відкрив форму гравця. Пульт і нова глядацька вкладка завантажили
той самий index-WZDAM7bf.js. Посилання локального TV онлайн веде в /api/app-shell.
Реальне вимкнення мережі на встановленому PWA у цій перевірці не виконувалось.

Перед деплоєм повторно зафіксовано стару оболонку публічного глядача:
звичайна коренева адреса завантажила index-CNQIaiT2.js при робочій версії 1.36.
Після деплою потрібно звірити точний файл нових вкладок із пультом і сервером.

Повне аудіо Deezer залишається [незавершеним](music-playback.md).
