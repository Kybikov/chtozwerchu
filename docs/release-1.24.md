# Реліз 1.24 — два джерела музики без втрати файлу

Пульт ведучого має явний вибір «Прев’ю» / «Мій файл». Під ним видно назву
власного файлу, стан вибору та окрему кнопку заміни. Усі дії використовують
спільну React Bits SpecularButton. Назва обрізається всередині картки;
кнопки мають висоту щонайменше 44 px, текст перемикача — 15 px.

Перехід на прев’ю отримує свіже посилання Deezer, перевіряє відповідність
запису та завантажує аудіо до події canplay в окремому елементі без
відтворення. Час очікування медіа обмежений 12 секундами, запиту API —
15 секундами. Перевірочний запит звільняється при успіху, помилці,
таймауті та скасуванні. Вибір іншого треку, відкриття підготовки або
вихід зі студії не дозволяють старій перевірці замінити поточний стан.

Помилка пошуку чи декодування залишає попереднє аудіо, прив’язку,
прихований рядок і рахунок. Власний файл не видаляється при виборі
прев’ю: до нього можна повернутися без мережі. Збережений вибір джерела
читається разом із метаданими, файлом і LRC. Після перезапуску недоступне
прев’ю не підмінюється повним записом із чужою для нього прив’язкою:
пульт пояснює стан і пропонує власний файл. Якщо власна копія відсутня,
потрібно додати її повторно або відкрити відповідну підготовку.

Успішна зміна джерела скидає прив’язку та зміщення, зберігаючи текст,
послівні проміжки, рахунок і рядок для відповіді. Перед стартом ведучий
перевіряє синхронізацію іншої версії аудіо. Під час музичного раунду та
відповіді зміна джерела недоступна. Перевірка джерела також утримує
встановлення оновлень PWA. Підготовлена програма після перезапуску
відновлює поточний вибір і живу прив’язку; явне відкриття іншої
підготовки використовує її власне аудіо та збережені параметри.

Редактор слів винесено в окремі JS/CSS-модулі. Вони входять до PWA-кешу
й відкриваються без сервера після першого завантаження застосунку.
Основний JS зменшився з 496.25 kB у 1.23 до 491.44 kB, хоча до студії
додано перевірку й збереження джерел. Початкове відкриття не виконує
код редактора слів.

Перевірено 67 фронтенд-тестів, production build, Go-тести та vet.
Браузерні сценарії охоплюють відсутній API, відповідь замість аудіо,
справжнє прев’ю Deezer, повернення до власного WAV без API, перезапуск
із вибраним прев’ю, скасування завислого запиту через редактор, чотири
власні підготовки та перезапуск програми зі зміненим джерелом і рядком.
Редактор слів відкрито вперше при вимкненому локальному HTTP-сервері.
На 320 px довга назва файлу не створює горизонтального прокручування;
стан очікування й кнопки також залишаються в межах картки. TV 1280×720
використовує сцену без пульта й шапки.

Повне аудіо Deezer залишається [незавершеним](music-playback.md).
Пошук, нові прев’ю та серверні кімнати потребують мережі. Власні файли
й підготовки зберігаються на тому пристрої, де їх додано.
