# Реліз 1.36 — узгоджені переходи між пультом і сценою

Сім навігаційних дій тепер використовують спільний ButtonLink на основі
React Bits SpecularButton: TV-вікно студії, приватний мережевий пульт,
глядацький екран конкурсів, приватний TV зі звуком та переходи з пульта
чи недоступної сцени. Раніше частина мала ручні класи й вкладені span,
а два TV-переходи виглядали як неоформлені текстові посилання.

Button і ButtonLink мають спільні параметри поверхні. У SpecularButton
додано локальний режим linkProps зі справжнім anchor: href, target, rel,
нативні клавіші та можливість скопіювати адресу зберігаються. Кнопки й
посилання використовують один вміст і стилі. Інтерактивні елементи не
вкладаються один в одного, додаткових canvas для посилань немає.
Шейдер і правила гри не змінені; нових залежностей немає.

## Перевірка

113 фронтенд-тестів, typecheck, production build, Go tests і vet пройшли.
У браузері на ізольованому Go-сервері Enter і натиск відкрили глядацьку сцену
конкурсів у нових вкладках. Глядач не має кнопок ведучого. Приватний TV-перехід
передав свою наявну можливість підключення, і пульт підтвердив «TV підключений».
TV-вікно музичної студії отримало синхронізовану сцену через BroadcastChannel.
З недійсного мережевого пульта посилання повернуло на головну.

На ширині 320 px TV-перехід має шрифт 16 px, висоту близько 70 px,
доступну й повну ширину 243 px. Є одна оболонка підпису, немає вкладених
кнопок чи додаткового canvas. Звичайні кнопки створення, початку,
відкриття слова та зарахування 4 балів також перевірено в браузері.

Джерело SpecularButton повторно отримано з реєстру React Bits перед адаптацією.
Повне аудіо Deezer залишається [незавершеним](music-playback.md).
