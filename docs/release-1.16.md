# Реліз 1.16 — налаштування вечора конкурсів

Форма створення гри має три розділи: «Твоя компанія», «Програма вечора»
та «Правила гри». Підписи, поля та пояснення режимів стали більшими.
Кнопка «Зібрати компанію» і підсумок кількості раундів та конкурсів
розташовані окремо від налаштувань. На великому екрані прокручується
панель налаштувань; на телефоні кнопка закріплена внизу.

Приєднання за кодом використовує ту саму форму та оформлення.
Помилка імені чи коду переводить фокус у відповідне поле. Для ширини
320 px прибрана мінімальна ширина сторінки, яка спричиняла горизонтальне
прокручування; додатковий нижній відступ дозволяє прочитати поля над
панеллю з помилкою.

Кнопки SpecularButton, панель SpotlightCard, шрифти Oswald та Onest і
кольори двох команд збережені. Замість трьох декоративних плиток є
окрема ілюстрація мікрофона, кнопок команд та карток, оптимізована у WebP.
Нових бібліотек немає.

Усі налаштування та значення за замовчуванням збережені. Створення кімнати,
гостьове приєднання, правила конкурсів, лобі, пульт та TV не змінювалися.
Повний стримінг через провайдера залишається [незавершеним](music-playback.md).
