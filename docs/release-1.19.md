# Реліз 1.19 — вхід та особиста історія

Вхід, реєстрація й профіль продовжують шкалу тексту Oswald + Onest зі
студії та конкурсів. Збільшені назви ігор, рахунок, дати, результати й деталі
раундів. На телефоні рахунок переходить під назву, деталі раунду мають
окремий рядок для оцінки, а кнопки залишаються доступними без зменшення
тексту. Картки історії використовують наявний React Bits SpotlightCard;
кнопки — SpecularButton. Стилі обмежені вікнами акаунта.

Форма показує локальну помилку біля відповідного поля, позначає його через
aria-invalid, пов’язує з повідомленням та переводить туди фокус. Поля мають
окремі підписи; кнопка показу пароля більше не потрапляє до назви поля.
Реєстрація перевіряє поля у видимому порядку й залишає вимогу до довжини
пароля видимою після введення. Серверні помилки входу залишаються спільними,
без припущення, яке з облікових даних неправильне. Власна валідація зберігає
оформлення повідомлень без браузерних спливаючих підказок.

Кнопка «Продовжити гостем» закриває форму на поточному екрані й очищає
пароль. Вона доступна також за недоступності сервісу акаунтів. Раніше на
цьому місці був технічний підпис про серверні музичні ключі.

Якщо сеанс відкликано, наприклад виходом в іншій вкладці, запит приватної
історії повертає до входу з поясненням. Попередня ідентичність і пароль
очищаються. Раніше профіль залишався відкритим із кнопкою повторного
завантаження, яка знову отримувала відмову. Після повторного входу історія
завантажується звичайним шляхом. Скасовані запити попереднього профілю не
оновлюють його стан.

Дані ігор, маршрути акаунтів, cookie-сесії та правила оцінювання збережені.
У підписі особистого рахунку використано українські форми «бал/бали/балів».
Повне аудіо провайдера залишається [незавершеним](music-playback.md).
