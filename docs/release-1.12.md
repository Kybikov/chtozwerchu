# Реліз 1.12 — програма музичного вечора

Перед приходом гостей ведучий збирає 4, 8, 12 або 16 підготовлених пісень
у власному порядку. Кожен запис — окремий раунд, команди ходять по черзі.
Назву вечора видно на сцені; майбутні пісні, аудіо й відповіді глядачам
не передаються.

1. Збережи потрібні записи через «Зберегти підготовку» у студії.
2. Відкрий «Програма вечора», введи назву й додай пісні.
3. Кнопками зі стрілками зміни порядок. Чернетку можна зберегти й відкрити
   пізніше на цьому пристрої, також після оновлення застосунку.
4. «Почати програму» перевіряє всі підготовки та відкриває першу пісню.
   Якщо вже є рахунок чи зіграні раунди, заміну гри потрібно підтвердити.
5. Після оцінки відповіді «Наступний раунд» відкриває наступний підготовлений
   запис. Відтворення починається лише за командою ведучого.
6. «Порядок вечора» показує пройдені, поточний та майбутні раунди у студії
   та на телефонному пульті. «Обирати пісні вручну» вимикає послідовність,
   зберігаючи рахунок та історію.

Відсутня наступна підготовка в каталозі або від’єднаний пристрій сцени не
змінюють номер раунду й оцінку. Якщо сам файл зник уже після передавання
каталогу, новий раунд залишається без оцінки до вибору доступної пісні;
ведучий може перейти до ручного вибору. Сервер перевіряє порядок, готовність нового аудіо,
повторні команди й відповідність підготовки поточному раунду. Програма
зберігається зі станом мережевої кімнати в Redis; після відновлення під час
завантаження сцена повторно відкриває потрібну підготовку без запуску музики.

Новий редактор використовує наявні React Bits SpecularButton і SpotlightCard,
шрифт Oswald для великих заголовків, Onest для керування та власні поля.
Кнопки перестановки доступні з клавіатури. Мобільний список перебудовується
без горизонтального прокручування. Окремі підготовки та їхні аудіофайли
залишаються у бібліотеці після зміни або вимкнення програми.

У програмі кожен запис трапляється один раз. Можна зберегти одну чернетку;
це ще не бібліотека кількох названих сценаріїв. Кількість раундів обмежена
4, 8, 12 і 16, щоб команди мали однакову кількість ходів. Активну програму
не можна переставляти посеред відповіді; зміна чернетки не переписує гру.

Для підготовлених прев’ю поновлюємо підписане посилання на той самий запис,
залишаючи збережені слова, часові мітки й обраний рядок. Прев’ю потребує
музичного API та мережі; підготовка з власним файлом відкривається без них.
Повний стримінг Deezer та автоматичне розпізнавання міток слів не додані.
Їхні поточні межі описані в [релізі 1.10](release-1.10.md).
