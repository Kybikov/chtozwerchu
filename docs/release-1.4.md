# Реліз 1.4 — домашнє шоу

## Для гравців

- Нова головна з великою типографікою Oswald, музичною графікою та вибором формату.
- Музична студія «Продовж пісню» відкривається через `/?screen=studio`.
- «Вечір конкурсів» у React: 5 слів, мелодії, Аліас, емодзі-ребуси, правда/брехня.
- Власні назви команд, 5/10/15/20 раундів, кімнати за кодом, окрема глядацька сцена.
- Приватні картки ведучого та того, хто пояснює. Сервер не надсилає їх глядачам.
- Пауза, відновлення участі, відновлення кімнат після перезапуску сервера.
- Реєстрація, вхід, вихід і приватна історія. Для гри достатньо гостьового імені.
- Завершена локальна музична гра може зберігатися у профілі. Гостьова партія зберігається лише за явним натисканням.
- Реальні прев’ю Deezer у конкурсі мелодій. Таймер очікує запуску звуку.
- Бали мелодії зменшуються з часом та підказками. Відсутність фрагмента позначається явно.
- Єдиний PWA-реєстратор для всіх екранів. Встановлення доступне з головної, оновлення — вручну.

## Дані та доступ

Сеанс акаунта: випадкова cookie HttpOnly/SameSite=Lax, Secure під HTTPS.
У PostgreSQL зберігається SHA-256 токена; вихід відкликає сеанс. Новий UI не
одержує bearer-токен і не зберігає пароль чи музичні ключі у сховищі браузера.
Історія фільтрується сервером за власником. Повторна спроба збереження не
створює ще один матч. Для старого API збережена сумісність bearer-авторизації.

Стан музичних і звичайних кімнат живе у приватному постійному томі, окремо
від фронтенда. Знімки звичайних кімнат містять приховані картки й ключі
учасників, тому їх не можна публікувати. Після відновлення гра залишається на
паузі. Ключі нових учасників мають 256 біт випадковості.

Deezer ARL доступний тільки серверному процесу. Фронтенд отримує публічні
метадані, URL прев’ю та синхронізований текст, а не ключ підключення.

## Перевірки

- `npm test`, `npm run typecheck`, `npm run build`.
- `go test ./...`, `go vet ./...`.
- Дві інтеграційні перевірки з окремим PostgreSQL: cookies/приватна історія/вихід та акаунт → WebSocket → фінал → ідемпотентна історія.
- Відновлення стану всіх п’яти конкурсів із приватного знімка.
- У браузері: реєстрація, жива партія з п’яти конкурсів, музика, підказки,
  прихована картка на TV, фінал, запис 7:5 у профілі.
- Перезапуск локального сервера під час паузи: той самий код, ведучий,
  рахунок і залишок часу відновилися.

CI запускає також `go test -race ./...` на Linux. Локальна Windows-перевірка
без CGO не замінює цей запуск.

## Межі версії

Це один авторитетний інстанс гри. Redis зберігає публічні знімки; маршрутизація
кімнат між кількома інстансами та pub/sub ще потребують реалізації.
«Правда чи брехня» приймає одну спільну відповідь активної команди, а не
індивідуальне голосування всіх учасників.

Прев’ю мають близько 30 секунд. Повний захищений потік Deezer не інтегрований.
Для повної музичної гри використовується власний аудіофайл. Точна підсвітка
слів потребує справжніх міток Enhanced LRC; Deezer зараз дає таймінги рядків.
У конкурсі мелодій звук іде з пристрою, на якому його ввімкнули.
