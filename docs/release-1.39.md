# Реліз 1.39 — спільна фінальна сцена

Музична студія та вечір конкурсів використовують один FinalShowcase:
велика назва переможця, рахунок із назвами обох команд і об'ємний кубок
у кольорах сцени. Рожева та синя команда мають відповідний колір перемоги,
нічия — окремий нейтральний заголовок. Дані рахунку й переможця надходять
із наявного стану гри; правила й нарахування не змінені.

Заголовок відкривається через React Bits BlurText, цифри — CountUp.
Їхні актуальні джерела й props звірені з registry React Bits перед використанням.
Компоненти не переписувалися. За prefers-reduced-motion цей блок відразу
показує статичний заголовок і фінальні цифри. Додаткового WebGL немає.

Композиція залежить від ширини самого блоку: в широкій сцені графіка праворуч,
на телефоні — над результатом. TV-розмір назви переможця — 70,2 px на Full HD
та 140 px на 4K. Великі числові значення підлаштовують розмір цифр, зберігаючи
повний рахунок. Кубок — прозорий WebP 1254 × 1254, 217 902 байти; його
додано до PWA precache. [Джерело й промпт графіки](show-trophy-v1.md).

## Перевірка

130 фронтенд-тестів, typecheck, production build, Go tests і vet пройшли.
У браузері перевірені перемоги обох команд, нічия, назви з 32 широких
кириличних символів і рахунок 10000:9999 на власних тестових кімнатах.
На 320 px у музичного й конкурсного фіналу немає горизонтального переповнення.
На 1280 × 720, 1920 × 1080 і 3840 × 2160 перевірено межі сцени;
навіть крайній музичний результат уміщується без вертикальної прокрутки.
Відмова від анімації перевірена у коді, без зміни системних налаштувань користувача.

Повне аудіо Deezer залишається [незавершеним](music-playback.md).
