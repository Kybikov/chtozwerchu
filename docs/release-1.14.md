# Реліз 1.14 — підготовка музики без зайвих переходів

Вікно «Музика й текст — разом» має власний плеєр React Bits WakeSlider:
перемотування, повернення на п’ять секунд, початок аудіо, поточну позицію
та рядок тексту. Ведучий може знайти початок рядка й одразу прив’язати його,
не закриваючи вікно. Прив’язка читає актуальний `audio.currentTime`.

Після прив’язки кожен рядок у межах аудіо можна прослухати окремо.
Відтворення починається з його реальної позиції та зупиняється в кінці.
Мітки перераховуються через поточне зміщення, без оцінки за довжиною тексту.
Рядки, що не вміщаються у файл або прев’ю, мають вимкнену кнопку слухання.
Зміна прив’язки, перемотування під час прослуховування, перехід до редактора
слів і закриття вікна зупиняють окремий рядок. Швидкий вибір іншого рядка
скасовує попередній фрагмент. Перевірка не запускає раунд і не змінює бали.

На ноутбуці плеєр і рядки розташовані поруч. На телефоні вони йдуть послідовно.
Текст рядка — 17–18 px, робочі кнопки — від 14 px, кнопки з іконками — 44 px.
У вікні є три кроки: прослухати, прив’язати текст, обрати відповідь.
Імпорт та експорт LRC залишаються поруч унизу; пошук має окремий порожній стан.
Використовуються наявні React Bits SpecularButton та WakeSlider без нових
залежностей і без видимих стандартних елементів браузера.

Послівні мітки Deezer з 1.13 зберігаються. Тип аудіо не змінюється:
доступні прев’ю або власний файл. Повний захищений стримінг не інтегрований.
Мережевий пульт і глядацька проєкція зберігають свій протокол; підготовка
відбувається на пристрої, що відтворює звук.
